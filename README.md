# 3D DUNGEON EXPLORER (30×30マス・5階建て立体迷宮)

ウィザードリィ（Wizardry）の雰囲気を再現した、クラシックなステップ移動式3Dダンジョン探索Webゲームです。  
戦闘や複雑なアイテム管理を排し、**「1フロアあたり30×30マスの広大な5階建て立体ダンジョン」**を歩き回り、マッピングしながら踏破することに特化した純粋な探索RPGです。

---

## 🎮 ゲームの特徴

1. **1フロアあたり30×30マス × 5階層の本格立体迷宮**
   - 1フロア900マス、全5フロアで合計4,500マスの広大な迷宮。
   - 上り階段・下り階段が上下の階層で直結したリアルな立体構造。
   - 複線的な昇降階段ネットワークにより、「別のフロアを経由して迂回する」といった立体迷宮ならではの探索パズル。
   - 各階層ごとの固有テーマ（1F石造、2F翡翠、3F氷晶、4F赤鉄、5F星幽聖殿）。

2. **切り替え式オートマップ（踏破マップ）**
   - 歩いたマスや視界に入った壁が自動的に記録される「Fog of War（視界の霧）」システム。
   - `[M]` キーまたは「🗺️ MAP」ボタンで、3Dビューと2Dオートマップを瞬時に切り替え可能。
   - オートマップ上部の「1F〜5F」ボタンで、いつでも各フロアの踏破状況を確認可能。

3. **快適な探索支援＆達成リザルト**
   - ヘッダーに現在のフロア（1F〜5F）、向いている方角（N/E/S/W）、座標（X/Y）、総歩数、全体の踏破率（%）を常時表示。
   - 各フロアの踏破率が 25%, 50%, 75%, 100% に到達するごとにマイルストーン通知。
   - 最上層5Fの中央にある「星幽の天頂碑」へ到達すると、迷宮踏破記念リザルト（歩数、踏破率、所要時間）が表示されます。もちろんその後も全フロア100%踏破を目指して探索を継続できます！

4. **Web Audio API によるレトロ効果音**
   - 外部音声ファイルの読み込み不要。ブラウザの内蔵シンセサイザー機能により、足音、階段昇降、扉開閉、回転床、クリアジングルが鳴り響きます（消音トグル付き）。

5. **モバイル対応＆自動セーブ**
   - スマホ・タブレットでも快適に遊べるタッチ用十字キー・アクションボタンを完備。
   - LocalStorageによるオートセーブ機能により、ブラウザを閉じてもいつでも続きから探索可能です。

## 🕹️ 操作方法

### PC（キーボード）
| キー | 操作内容 |
| :--- | :--- |
| **W** / **↑** | 前進 |
| **S** / **↓** | 後退 |
| **A** | 左へ平行移動 (Strafe Left) |
| **D** | 右へ平行移動 (Strafe Right) |
| **Q** / **←** | 左へ90度旋回 |
| **E** / **→** | 右へ90度旋回 |
| **Space** / **Enter** | 調べる (階段の昇降、扉を開ける、怪しい壁を調べる) |
| **M** | 3D視点 / オートマップ 表示切り替え |

### スマートフォン / タッチデバイス
- 画面下の **仮想D-PAD**（前進・後退・平行移動・旋回）をタップして移動できます。
- **「🔍 調べる」** ボタンで目の前の対象や足元の階段を調べられます。
- **「🗺️ マップ切替」** ボタンでマップを表示・非表示できます。

## 🚀 GitHub にあげて GitHub Pages でプレイする手順

このゲームは外部ライブラリやビルドツールを一切使用していない純粋な HTML / CSS / JavaScript 製のため、**GitHub Pages ですぐに世界中に公開できます。**

### ステップ1: GitHub にプッシュする
```bash
git add .
git commit -m "Update: 30x30 5-floor vertical dungeon explorer"
git push origin main
```

### ステップ2: GitHub Pages を有効化する
1. GitHubの該当リポジトリのページを開きます。
2. 上部メニューの **「Settings」** をクリックします。
3. 左サイドバーにある **「Pages」** をクリックします。
4. **「Branch」** で `main` ブランチ、フォルダは `/ (root)` を選択し、**「Save」** をクリックします。
5. 数分待つと公開URLが表示され、PCでもスマートフォンでも即座にプレイ可能です！
